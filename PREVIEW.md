# Landing Page Preview

Para conferir a versão atual da landing page:

1. Inicie um servidor local na raiz do projeto:
   ```bash
   python3 -m http.server 8000
   ```
2. Acesse [http://localhost:8000/](http://localhost:8000/) no navegador para carregar o `index.html`.
3. Atualize a página sempre que fizer mudanças para visualizar o resultado mais recente.
